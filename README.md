# 📝 To-Do List

Lista de tarefas simples e direta, feita com HTML, CSS e JavaScript puro, sem frameworks.

🔗 **Demo:** [to-do-list-mu-nine-53.vercel.app](https://to-do-list-mu-nine-53.vercel.app)

## ✨ Funcionalidades

👉 CONFIRMAR e ajustar conforme o código:
- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Os dados continuam salvos após recarregar a página (localStorage)?

## 📁 Estrutura

```
to-do-list/
├── css/          # Estilos
├── images/       # Imagens e captura de tela
├── js/           # Lógica da aplicação
└── index.html    # Página principal
```

## 🚀 Como executar

Não precisa instalar nada:

```bash
git clone https://github.com/EricPfeuti/to-do-list.git
cd to-do-list
```

Abra o arquivo `index.html` no navegador (ou use a extensão Live Server do VS Code).
